Fluid Mechanics: Interactive Course Guide

A guide to the core of an introductory fluid mechanics course. It covers dimensional analysis and similarity, control volume analysis, pressure and hydrostatics, and continuity and Bernoulli. Each topic has the key equations with every variable explained, live calculators and worked examples.

Overview

Four connected topics. Each one builds a tool for solving real flow problems.

1. Dimensional analysis

Reduce a problem to dimensionless groups with the Buckingham Pi method. Use them to scale model tests to full-size machines.

2. Control volume

Apply conservation of mass and linear momentum to a fixed region. Find the forces on pipes, bends, nozzles and junctions.

3. Pressure and hydrostatics

Pressure in a fluid at rest, manometers, and the force and centre of pressure on submerged surfaces.

4. Continuity and Bernoulli

Relate speed, pressure and height in a flowing fluid. Apply it to Pitot probes, venturi meters, tanks, jets and siphons.

How the topics connect

  • Pressure and hydrostatics gives the pressure forces used everywhere else.
  • Continuity and Bernoulli links speed, pressure and height.
  • Control volume analysis combines both to give forces from flowing fluid.
  • Dimensional analysis stands apart. It applies to every topic and guides experiments.

How to use this page

1. Dimensional analysis and similarity

How to reduce a physical problem to dimensionless groups, and use them to scale model tests to full size.

Objectives

  • List the variables and their dimensions (M, L, T).
  • Pick three repeating variables.
  • Build each Pi group.
  • Use matching Pi groups to scale a model test to a prototype.

Learn it

Physics must not depend on the unit system. So every valid equation equates dimensionless groups. Buckingham Pi: a problem with n variables built from k basic dimensions (M, L, T so k = 3) reduces to n − k dimensionless groups.

Π1 = f(Π2, Π3, …)

Repeating variables: a set of k variables (here 3) that together contain M, L and T and cannot form a dimensionless group among themselves. They appear in every Pi group. Non-repeating variables: all others. Each non-repeating variable gets its own group, built by multiplying it with the repeating variables raised to powers.

Rules for choosing repeating variables: one geometry variable (D, L), one flow-property variable (V, Ω), one fluid-property variable (ρ). Never pick the quantity you want to find (force, power, thrust) and never a dimensionless variable.

Steps

  1. Write the dependent variable as a function of all the others.
  2. Write each variable's dimensions in M, L, T.
  3. Count: n variables, k = 3, so n − 3 groups.
  4. Pick 3 repeating variables.
  5. For each other variable v: Π = v · r1a · r2b · r3c. Solve a, b, c so M, L, T exponents all equal zero.
  6. Check each group is dimensionless.

Similarity: model to prototype

Geometric similarity: same shape, scaled lengths. Kinematic similarity: same velocity pattern. Dynamic similarity: same force ratios. You get dynamic similarity when every independent Pi group matches between model (m) and prototype (p). Then the dependent Pi group matches too, and you scale the measurement.

A. Propeller model test

Groups: Π1 = V/(ND), Π2 = T/(ρN²D⁴). Density from ρ = p/(RT) with R = 287 J/kg/K.

B. Vehicle drag model test

Groups: Π1 = D/(ρV²A), Π2 = ρV√A/μ. Match Reynolds number to find Vm.

Analogy

A recipe in cups versus a recipe in ratios. "Two parts flour to one part water" works in any size kitchen. Pi groups are the ratios. A 1/6 propeller behaves like the big one when the ratios match, even though every number is different.

2. Control volume: mass and momentum

Analysis of flowing fluid through a fixed region: conservation of mass and linear momentum, and the forces on pipes, bends and nozzles.

Objectives

  • Define extensive and intensive properties and relate them.
  • Draw a control volume with all velocities, pressures and forces.
  • Use continuity to find unknown velocities.
  • Use linear momentum to find the force that holds a pipe, bend or nozzle.

Learn it

Extensive property depends on the amount of fluid: mass, momentum, energy, volume. Intensive property does not: density, pressure, temperature, velocity. Dividing extensive B by mass gives intensive b.

b = B / m    (B = m, momentum mV, energy E; then b = 1, V, e)

Physics laws apply to a fixed piece of fluid (a system). A control volume (CV) is a fixed region in space. The Reynolds Transport Theorem links the two:

dBsys/dt = d/dt ∫CV ρ b dV + ∫CS ρ b (V·n) dA
  • First term: how much B builds up inside the CV.
  • Second term: net B leaving through the control surface (CS).
  • V·n is positive at outflow, negative at inflow.

Mass (B = m, b = 1)

0 = d/dt ∫ρ dV + ∫ρ(V·n) dA

Steady, uniform, incompressible: ΣQin = ΣQout, with Q = VA.

Linear momentum (B = mV, b = V)

ΣF = d/dt ∫ρV dV + ∫ρV(V·n) dA

Steady, uniform sections: ΣF = Σ ṁoutVout − Σ ṁinVin, with ṁ = ρVA.

Forces in ΣF

  • Pressure: pgA, directed into the CV, normal to the cut surface. Use gauge pressure: atmosphere pushes equally on all sides and cancels.
  • Weight: W, downward. Include the fluid inside the CV when the problem gives its volume.
  • Support force R: the unknown. The force the device feels is −R.

Solving routine

  1. Draw the CV so the cuts go through pipe sections where p and V are known. Dashed line.
  2. Pick axes. Mark every V, p, A, and every unknown force.
  3. Continuity gives the unknown velocities.
  4. Write each force in x and y with signs.
  5. Write x momentum and y momentum: ΣF = ṁVout − ṁVin.
  6. Solve Rx, Ry.

Force calculator: two-port device (bend, nozzle, U-turn)

Inlet flows along +x. The outlet leaves at angle θ from +x (0° = straight nozzle, 90° = elbow turning to +y, 180° = U-turn back along −x). Pressures are gauge.

Formula used: R = ṁ(V2d̂ − V1x̂) − p1A1x̂ + p2A2d̂, plus W added to Ry (weight acts down, so Ry carries it up). Here d̂ is the outlet flow direction. R is the force from the bolts on the CV.

Worked example: T-junction

Water, all pipes D = 1 m. Section 1 (branch along x): V1 = 5 m/s, p1 = 220 kPa. Section 2 (inflow, along y): p2 = 134 kPa. Section 3 (outflow, along y): Q3 = 15 m³/s, p3 = 52 kPa. All gauge.

Objectives and variables
  • Find V2, V3.
  • Find Fx, Fy that hold the junction.

Variables: A = πD²/4 = 0.7854 m². Q = VA. ṁ = ρQ.

Solution
CV: dashed box around the junction, cutting sections 1, 2, 3. Axes: x along branch 1, y along the main pipe positive toward section 2.
Continuity: Q1 = V1A = 3.927 m³/s. Mass balance Q1 + Q2 = Q3 gives Q2 = 11.073 m³/s.
Velocities: V2 = Q2/A = 14.10 m/s. V3 = Q3/A = 19.10 m/s.
x momentum. Only section 1 has x flow. Pressure p1A pushes along +x. Rx + p1A = 0 − ρQ1V1. So Rx = −(220 000 × 0.7854 + 1000 × 3.927 × 5) = −192.4 kN.
y momentum. Section 2 flow moves in −y (in). Section 3 flow moves in −y (out). Pressure p2A acts in −y. Pressure p3A acts in +y.
Ry − p2A + p3A = (−ρQ3V3) − (−ρQ2V2).
Ry = −286.5 + 156.1 + 105.2 − 40.8 = −66.0 kN.

The anchor must push with 192 kN along −x and 66 kN along −y. The junction feels the opposite. The sign of Ry follows the axis direction chosen.

Analogy

Count people through a doorway. The CV is the room. Momentum in the room changes only when people carrying momentum enter or leave, or when someone pushes. The wall pushing back is R. A firehose crew leans back on the nozzle for the same reason: fast water leaves, so the hose must supply a forward force on the water, and the water pushes back.

3. Pressure and hydrostatics

Pressure in a fluid at rest, manometers, and the force and centre of pressure on submerged surfaces.

Objectives

  • Relate absolute, gauge and atmospheric pressure.
  • Read multi-fluid manometers.
  • Find the force and centre of pressure on a plane gate.
  • Take moments about a hinge.

Learn it

pabs = patm + pgauge     p = p0 + ρgh = p0 + γh

Same fluid, same height, same pressure. Pressure rises with depth. Going down through a fluid adds γh. Going up subtracts γh. Use this for every manometer.

Force on a plane surface

F = γ hc A     hcp = hc + Ixx / (A hc)     rectangle: Ixx = bd³/12
SymbolMeaning
γspecific weight = ρg (water 9810 N/m³)
hcvertical depth of the centroid below the free surface
Aarea of the surface
Ixxsecond moment of area about the centroidal horizontal axis
hcpdepth of the centre of pressure, always at or below the centroid
d, bgate height along the slope and gate width

Inclined gate: use distances along the slope for I/(Ayc), and h = y sinθ for pressure. Pressurised tank: replace the free surface with an equivalent surface at p0/γ above the liquid surface.

Accelerating tank (for example a rocket tank at 9g upward): replace g with (g + a). Pressure at depth h becomes p0 + ρ(g + a)h.

Hinge: take moments about the hinge. Fcp times its lever arm equals the applied force times its lever arm. Zero hinge reaction means the applied force acts at the centre of pressure.

Gate calculator

Find depth h from the centre-of-pressure height

hcp − hc = d²/(12hc). Gate bottom on floor, so hc = h − d/2 and cp at depth h − e (e = height above floor). Then hc = d²/(12(d/2 − e)).

Manometer reader and pressure difference

One rule: start at a known pressure, add γh going down, subtract γh going up, stop at the unknown.

Differential U-tube: Δp = (ρm − ρ)gH. Inverted U-tube with a light fluid: Δp = (ρ − ρm)gH.

Worked example: gate with known centre of pressure

  • Gate 1.8 m tall, 1.5 m wide, hinge at top. Resultant acts 0.8 m above the tank bottom.
  • Find h, F, hinge force.
Solution
A = 1.8 × 1.5 = 2.7 m². Ixx/A = d²/12 = 0.27 m².
Gate bottom sits on the floor. Centroid depth hc = h − 0.9. Centre of pressure depth = h − 0.8.
hcp − hc = 0.1 = 0.27/hc. So hc = 2.7 m. h = 3.6 m.
F = γhcA = 9810 × 2.7 × 2.7 = 71.5 kN.
F is applied by the load at the same height as the resultant, so moments about the hinge balance with no help from the hinge. Hinge force = 0.

Analogy

Stack books on your hand. The bottom book carries every book above it. The load grows with depth, so the total push is stronger low down and the balance point sits below the middle of the stack.

4. Continuity and Bernoulli

Continuity and Bernoulli's equation, with applications to flow measurement, tanks, jets and siphons.

Objectives

  • Apply Q = V1A1 = V2A2.
  • Apply Bernoulli between two points on a streamline.
  • Read a Pitot-static probe, venturi and manometer.
  • Handle tanks, jets and siphons, with and without friction loss.

Learn it

p1 + ½ρV1² + ρgz1 = p2 + ½ρV2² + ρgz2

Derivation: work done by pressure on a fluid slice equals the gain in potential and kinetic energy. Divide by the volume swept.

TermNameMeaning
pstatic pressurethermodynamic pressure a moving gauge would read
½ρV²dynamic pressurekinetic energy per volume
ρgzhydrostatic termpotential energy per volume
p + ½ρV²stagnation (total) pressurewhat a Pitot tube reads where V = 0

Four conditions. All four, or the equation fails.

  1. Steady.
  2. Incompressible.
  3. Inviscid (no friction).
  4. Along one streamline.

Fails in boundary layers, wakes and separated flow. Works well outside them.

Continuity and variable area

Q = VA = constant    so small area means high velocity and low pressure.

Applications

  • Pitot-static: p0 − p = ½ρV², so V = √(2(p0 − p)/ρ).
  • Venturi: V1A1 = V2A2, p1 − p2 = ½ρ(V2² − V1²). Real flow: multiply by discharge coefficient Cd.
  • Free jet from a tank: V = √(2gh). For stacked liquids, convert layers to pressure: V = √(2(Σγh)/ρ) with a bottom liquid.
  • Siphon with loss: z1 = z2 + V²/2g + hf, with hf = K V²/2g.
  • Rotating pipe: add centrifugal potential. p/ρ + V²/2 + gz − ω²r²/2 = constant.

Total and static pressure in a converging-diverging duct: total pressure stays the same from inlet to throat (no loss). Static pressure drops at the throat because velocity rises.

Pitot-static probe

Worked example: fire hose nozzle

Hose 10 cm, nozzle 3 cm, Q = 1.5 m³/min to atmosphere. Find p1 and bolt force.

Solution
Q = 0.025 m³/s. V1 = Q/A1 = 3.18 m/s. V2 = Q/A2 = 35.37 m/s.
Bernoulli (same height, p2 = 0 gauge): p1 = ½ρ(V2² − V1²) = 620 kPa gauge.
Momentum on the nozzle CV: p1A1 − FB = ṁ(V2 − V1). With ṁ = 25 kg/s: FB = 4873 − 805 = 4.07 kN.

Analogy

A hill with a ball. Total energy per kilo stays fixed. Height, speed and pressure trade against each other. If the ball rolls through mud (friction), total drops, so you subtract a loss term hf.
